MY RETA JOURNEY — VERSION 7 PWA

Upload ALL files/folders in this package together to an HTTPS static website.

Android: open the HTTPS site in Chrome, then tap Install App or browser menu → Install app / Add to Home screen.
iPhone/iPad: open the HTTPS site, then Share → Add to Home Screen.

The service worker caches the app shell for offline use. Journal data remains in browser local storage on that device. Use Backup My Data regularly, especially before clearing site data, changing devices, or uninstalling.
